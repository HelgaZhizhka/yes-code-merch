## 3 варианта дизайна каталога

### Вариант 1 — Classic Sidebar Accordion

Классический подход: левый сайдбар с accordion-секциями (Категории → Размер → Цвет → Цена → Наличие). Активные фильтры отображаются тегами над сайдбаром. Поиск + сортировка + переключатель вида в топ-баре контента. **Наиболее знакомый паттерн для e-commerce.**

### Вариант 2 — Horizontal Filter Pills

Фильтры в горизонтальной полосе под хедером — каждый фильтр это pill-кнопка с дропдауном. Слева — компактный список категорий с каунтерами. **Экономит вертикальное пространство, хорошо работает когда фильтров мало.**

### Вариант 3 — Bold Sidebar + Dark Search Bar

Editorial-стиль: тёмная полоса поиска на всю ширину под навом, жирный сайдбар с uppercase-заголовками и чекбоксами категорий + каунтерами. **Наиболее современный вид, выделяется среди конкурентов.**

---

- Дерево категорий с раскрытием и счётчиком товаров
